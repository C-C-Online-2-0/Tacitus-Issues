# Tacitus Issues

Public bug reports and feature requests for **Tacitus**, the C&C Online desktop client.

## What this repository is

- The public issue tracker for the Tacitus client.
- The place to report bugs, crashes, and regressions, and to suggest new features or improvements.

## What this repository is not

- **Not the source code.** Tacitus is closed source. This repository contains no client code and does not accept code contributions.
- **Not a support desk.** For general help, setup questions, or account problems, ask in the [C&C Online Discord](https://discord.cnc-online.net).
- **Not for security reports.** Never post vulnerabilities, exploits, or cheats publicly. Follow the [security policy](.github/SECURITY.md) instead.
- **Not for the games themselves.** Balance changes, game bugs, and issues with the C&C Online servers that are unrelated to the client belong elsewhere.

## Before opening an issue

- Search existing issues (including closed ones) to avoid duplicates.
- Update to the latest Tacitus version and check whether the problem still happens.
- Use the bug report or feature request form so the team has what it needs to triage.
- Do not include passwords, tokens, email addresses, or other personal data, including in attached logs and screenshots.

Issues are reviewed and triaged by the C&C Online team. Opening an issue does not guarantee that it will be implemented or fixed by a certain date.

## Pull requests

Because the code is private, pull requests cannot be reviewed or merged. They are closed automatically. Please open an issue instead.
